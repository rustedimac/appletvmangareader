# App themes from Theme Lab

`CeladonTheme` and `RisographTheme` are generated by
[Theme Lab](https://github.com/rustedimac/theme-lab) (`make apple`), from
`themes/celadon/` and `themes/risograph/` at commit `4a30625`. Don't edit them
here; change the theme in Theme Lab and re-export:

```sh
# in a theme-lab checkout
make apple THEME=celadon
make apple THEME=risograph
# then copy dist/apple/<slug>/ over Packages/Themes/<Name>Theme/ (without tokens.apple.json)
```

The app uses them through `App/Sources/Shared/Design/ThemeStyle.swift`, which
picks the few roles the tvOS screens need (ground, tint, headings, section
labels, secondary text) from each theme's palette. Every color it uses is one
of the theme's own contrast-checked pairs (`themes/<slug>/contrast.json`).

Heading fonts are bundled in `App/Resources/Fonts` (SIL Open Font License):
Alegreya Bold (a static instance of the Alegreya variable font) for Celadon and
Londrina Solid Black for Risograph. Body text stays in the system font, which
is what tvOS sizes and focus effects are tuned for.
